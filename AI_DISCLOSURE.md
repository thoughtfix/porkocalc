# AI Disclosure & Responsibility Policy

## Authorship

This project was conceived, orchestrated, and released by humans.

Opus models (through Anthropic's plugin for Visual Studio Code) were liberally used as a technical tool, particularly for error-prone tasks like mapping hex codes to keypresses and comparing our codebase against other open-source projects to ensure original authors receive proper credit. AI helped track down layers of function calls to sort out deeply buried methods, and with our own original code. (I admit AI had to report to a human that the human's original code or design may have technically worked, but was a bad idea.) Even so, every architectural and design choice was human-guided.

## Code Accountability vs. Tool Usage

We want to be entirely transparent about where responsibility lies:

**Code Quality & Bugs:** Humans take full responsibility for the code itself, including bugs, errors, and technical flaws from the first release onward. There is no such thing as "The AI wrote the bug" when it comes to software defects. If the code breaks or malfunctions technically, that responsibility rests with the author of the commit and its approvers.

**Scope of Responsibility (Pentesting):** Features of this code have the potential to be used as a penetration testing tool. While we are responsible for the source code we wrote and published, we assume zero responsibility for how others choose to use it. Users are solely responsible for ensuring their use of this tool complies with all applicable local, state, national, and international laws. Unauthorized access, targeting systems without explicit prior authorization, or any malicious misuse is strictly prohibited and entirely on the end-user. See DISCLAIMERS.md for the responsibility policy governing use of this software.
